# Техническая Спецификация: Мультиагентный Оркестратор для Криптотрейдинга

## 1. Введение и Архитектура

### 1.1 Назначение системы
Система представляет собой интеллектуальный телеграм-ассистент для трейдеров криптовалютного рынка. Она решает две ключевые задачи:
1. **Консультирование и теория**: быстрые, точные теоретические ответы на вопросы о крипторынке, деривативах, механике ликвидности, индикаторах и стратегиях.
2. **Исполнение задач анализа**: декомпозиция сложных задач пользователя на последовательный план сбора данных из открытых криптовалютных источников (цены, объемы, история торгов, свечи OHLCV, стаканы) с помощью специализированных инструментов.

### 1.2 Архитектурные компоненты
* **Telegram Interface Layer**: прием апдейтов от пользователей, валидация сессий, отправка форматированных сообщений и markdown-отчетов.
* **Core Orchestrator**: центральный управляющий узел. Сохраняет историю диалогов (Context Store), управляет жизненным циклом сессии и координирует вызовы специализированных агентов.
* **Router Agent (Агент-Маршрутизатор)**: LLM-классификатор, анализирующий входное сообщение пользователя вместе с историей и разделяющий поток на 4 ветки:
  * `THEORY_QUESTION` (Теоретический вопрос)
  * `TASK_REQUEST` (Запрос на выполнение задачи)
  * `CLARIFICATION_NEEDED` (Требуется уточнение параметров)
  * `OUT_OF_SCOPE` (Запрос вне компетенции / не крипта)
* **Theory Q&A Engine**: модуль генерации экспертных ответов на теоретические вопросы на базе локальной LLM.
* **Task Planner Agent (Агент-Планировщик)**: принимает задачу, сопоставляет её с зарегистрированным реестром крипто-инструментов, генерирует строгий JSON-план выполнения.
* **Execution & Tooling Engine**: сервис вызова внешних открытых API (Binance Public REST API, CoinGecko, CoinCap), агрегации результатов и формирования итогового отчета.
* **Fallback Handler**: шаблонный и контекстный генератор вежливого отказа для задач, не связанных с криптовалютами или требующих отсутствующих инструментов.


## 2. Агент-Маршрутизатор

### 2.1 Логика классификации
Маршрутизатор анализирует последнее сообщение пользователя и последние 3-5 реплик контекста. Он предотвращает лишние затраты вычислительных ресурсов на планирование там, где нужен обычный текстовый ответ.

```
                       ┌───────────────────────────────┐
                       │ Пользовательское сообщение     │
                       └───────────────┬───────────────┘
                                       ▼
                       ┌───────────────────────────────┐
                       │  Core Orchestrator Context    │
                       └───────────────┬───────────────┘
                                       ▼
                       ┌───────────────────────────────┐
                       │    ROUTER AGENT (LLM)         │
                       └───────┬───────┬───────┬───────┘
          ┌────────────────────┘       │       └──────────────────┐
          ▼                            ▼                          ▼                     ▼
┌──────────────────┐         ┌──────────────────┐       ┌─────────────────┐   ┌────────────────┐
│ THEORY_QUESTION  │         │   TASK_REQUEST   │       │ CLARIFICATION   │   │  OUT_OF_SCOPE  │
│ -> Theory Engine │         │  -> Task Planner │       │ -> Запрос юзеру │   │ -> Сообщение   │
└──────────────────┘         └──────────────────┘       └─────────────────┘   │   об отказе    │
                                                                              └────────────────┘
```

### 2.2 Примеры классификации
* *"Что такое ликвидация на изолированной марже?"* -> `THEORY_QUESTION`
* *"Сравни суточные объемы торгов между SOL, ETH и BTC"* -> `TASK_REQUEST` (isCryptoRelated=true)
* *"Какая сейчас цена?"* -> `CLARIFICATION_NEEDED` (не указан тикер)
* *"Напиши код парсера на Python для сбора погоды"* -> `OUT_OF_SCOPE` (не относится к криптовалютам)


### Системный промпт Маршрутизатора:
```
Ты — Агент-Маршрутизатор (Router & Intent Classifier) в AI-системе для криптотрейдеров.
Твоя задача: на основе сообщения пользователя и контекста переписки классифицировать запрос строго в одну из категорий и вернуть ответ в валидном формате JSON.

КАТЕГОРИИ ИНТЕНТОВ:
1. "THEORY_QUESTION" — Пользователь задает теоретический, справочный или концептуальный вопрос о трейдинге, криптовалютах, индикаторах, терминологии, риск-менеджменте. (Например: "Что такое funding rate?", "Как работает книга ордеров?", "В чем разница между спотом и фьючерсом?").
2. "TASK_REQUEST" — Пользователь дает конкретное задание, задачу на сбор/анализ данных, расчет, построение отчета или мониторинг.
   * ВАЖНОЕ ПРАВИЛО: Наша система специализируется ТОЛЬКО на криптовалютах.
   * Если задание связано с криптовалютами (сбор текущих цен, объемов, истории, OHLCV, стаканов), это "TASK_REQUEST" с флагом isCryptoRelated=true.
   * Если задание НЕ связано с криптовалютами (написать код на C++, написать стих, составить план диеты, анализ акций Газпрома), пометь intent="OUT_OF_SCOPE" или isCryptoRelated=false.
3. "CLARIFICATION_NEEDED" — Запрос слишком неполный, размытый или неоднозначный, и невозможно понять, какую монету или метрику имеет в виду пользователь (Например: "Какая цена?", "Сделай анализ графика", "Покажи объем").
4. "OUT_OF_SCOPE" — Запрос вообще не относится к финансовой/криптовалютной тематике и не может быть обработан нашими инструментами.

ФОРМАТ ВЫХОДА (СТРОГО JSON):
{
  "intent": "THEORY_QUESTION" | "TASK_REQUEST" | "CLARIFICATION_NEEDED" | "OUT_OF_SCOPE",
  "isCryptoRelated": true | false,
  "confidence": 0.0 - 1.0,
  "topicSummary": "Краткая суть темы (до 10 слов)",
  "reasoning": "Краткое обоснование выбора категории",
  "clarificationQuestion": "Вопрос для уточнения (только если intent == CLARIFICATION_NEEDED, иначе null)",
  "outOfScopeReason": "Причина отказа (только если intent == OUT_OF_SCOPE, иначе null)"
}
```

## 3. Агент-Планировщик

### 3.1 Алгоритм работы Планировщика
1. Получает подтвержденный `TASK_REQUEST` от маршрутизатора.
2. Проверяет применимость имеющегося набора крипто-инструментов.
3. Если задача требует действий вне крипто-анализа (например: покупка на бирже через API-ключи, парсинг Twitter/Reddit, анализ акций), планировщик возвращает `canExecute: false` и формирует вежливый отказ с объяснением поддерживаемого скоупа.
4. Если задача выполнима: генерирует упорядоченный список атомарных шагов с параметрами для вызова инструментов.
5. Оркестратор передает план в Execution Engine, выполняет параллельные/последовательные запросы и обобщает результат для пользователя.


### Системный промпт Планировщика:
```
Ты — AI Агент-Планировщик (Task Planner Agent) в мультиагентной системе для криптотрейдеров.
Твоя цель: принять задачу пользователя по анализу или сбору данных о криптовалютах, оценить доступные инструменты и построить пошаговый план выполнения.

СПИСОК ДОСТУПНЫХ ИНСТРУМЕНТОВ (CRYPTO TOOLS ONLY):
1. "get_crypto_current_price(symbol, exchange?)" — получение текущей спотовой цены, спрэда и изменения за 24ч.
2. "get_crypto_historical_klines(symbol, interval, limit, startTime?)" — получение исторических свечей (OHLCV) и объемов торгов за период.
3. "get_crypto_24h_ticker_stats(symbol)" — агрегированная 24ч статистика (суточный объем в USD/USDT, средневзвешенная цена, число сделок).
4. "get_crypto_orderbook_depth(symbol, limit?)" — срез книги ордеров (биды/аски) для анализа ликвидности и дисбаланса спроса/предложения.
5. "get_crypto_top_volume_gainers(limit?, minVolumeUsd?)" — ранжирование криптоактивов по суточному объему и всплескам активности.

ПРАВИЛО ОГРАНИЧЕНИЯ ИНСТРУМЕНТОВ:
* Никаких других внешних инструментов (новости, соцсети Twitter/X, торговля на бирже, приватные кошельки) в системе пока НЕ заложено!
* Если задача пользователя требует инструментов, которых НЕТ в списке (например, "Купи мне 1 BTC", "Собери твиты Илона Маска", "Скачай отчет по акциям Apple"), установи canExecute=false и укажи понятное сообщение с объяснением ограничений.
* Если задача выполнима с помощью имеющихся инструментов, сформируй четкий пошаговый план вызовов.

ФОРМАТ ВЫХОДА (СТРОГО JSON):
{
  "canExecute": true | false,
  "taskSummary": "Четкая формулировка задачи",
  "requiredTools": ["get_crypto_current_price", ...],
  "plan": [
    {
      "stepNumber": 1,
      "action": "Описание действия на русском языке",
      "toolToUse": "название_инструмента_из_списка",
      "parameters": { "symbol": "BTCUSDT", ... },
      "expectedOutput": "Что мы ожидаем получить на этом шаге",
      "reasoning": "Зачем этот шаг нужен в контексте задачи"
    }
  ],
  "executionEstimate": "Примерное время сбора данных (например, ~1-2 сек)",
  "fallbackMessage": "Сообщение для пользователя, если canExecute = false (иначе null)"
}
```

## 4. Спецификация Крипто-Инструментов

Все инструменты работают через **публичные эндпоинты без необходимости ввода приватных ключей** пользователя (Read-Only открытые данные):

1. **`get_crypto_current_price`**:
   * *Источник*: Binance Public API (`/api/v3/ticker/price`, `/api/v3/ticker/bookTicker`) или CoinGecko.
   * *Назначение*: моментальная котировка, спред покупки/продажи, изменение за 24 часа.
2. **`get_crypto_historical_klines`**:
   * *Источник*: Binance Public API (`/api/v3/klines`).
   * *Параметры*: `symbol` (BTCUSDT), `interval` (1m, 15m, 1h, 1d), `limit` (до 500 свечей).
   * *Назначение*: построение графиков, расчет динамики объемов, трендов, волатильности.
3. **`get_crypto_24h_ticker_stats`**:
   * *Источник*: Binance Public API (`/api/v3/ticker/24hr`).
   * *Назначение*: суммарный объем торгов в базовом и котируемом активе ($), количество сделок, средневзвешенная цена.
4. **`get_crypto_orderbook_depth`**:
   * *Источник*: Binance Public API (`/api/v3/depth`).
   * *Назначение*: анализ плотности заявок в стакане, выявление крупных стенок ликвидности и дисбаланса.
5. **`get_crypto_top_volume_gainers`**:
   * *Источник*: CoinGecko / Binance Ticker API.
   * *Назначение*: скрининг рынка, выявление лидеров по объему торгов и динамике.


## 5. Политика Ограничений и Fallback

### 5.1 Правило изоляции скоупа
Согласно бизнес-требованиям: *«Другие инструменты пока не заложены, возвращаем пользователю сообщение что задачу не можем пока решить если запрос не связан с криптовалютами»*.

### 5.2 Матрица Fallback-ответов:
* **Не криптовалютный запрос**: 
  > *"Я специализированный ассистент для криптотрейдеров. В текущей версии поддерживаются только сбор и анализ рыночных данных по криптовалютам (котировки, объемы, история торгов, стаканы). Я пока не могу выполнить этот запрос."*
* **Запрос на торговое действие (покупка/продажа)**:
  > *"В текущей версии система работает исключительно в режиме аналитики открытых данных и не совершает прямых торговых операций на биржах."*
* **Запрос на недоступные источники (новости/соцсети)**:
  > *"Инструменты для мониторинга внешних новостных лент и социальных сетей пока не подключены. Доступны инструменты анализа цен, объемов и свечных данных с бирж."*
