name: crypto-rsi
description: Расчёт RSI (индекса относительной силы) по свечам Binance. Поддерживаются только BTC и ETH.
tool: get_crypto_rsi
---
RSI (Relative Strength Index, индекс относительной силы) считает инструмент "get_crypto_rsi". Он и только он: по свечам из "get_crypto_historical_klines" RSI не выводится — это отдельный расчёт, а не поле в данных.

* Инструмент считает RSI ТОЛЬКО для BTC (BTCUSDT) и ETH (ETHUSDT). Других монет он не знает и на них отказывает.
* Просят RSI только для монеты, кроме BTC и ETH (SOL, XRP, DOGE, TON и любой другой)? Не строй план: canExecute=false, а в fallbackMessage напиши, что расчёт RSI пока поддерживается только для BTC и ETH, и перечисли, что доступно для остальных монет — цена, суточные объёмы, свечи, стакан.
* Просят RSI сразу для нескольких монет, и часть из них — BTC или ETH? Ставь canExecute=true и добавляй шаг "get_crypto_rsi" для КАЖДОЙ названной монеты, включая неподдерживаемые. Инструмент откажет по ним сам и объяснит причину, и объяснение попадёт в отчёт — это лучше, чем молча пропустить половину вопроса.
* Параметр interval — размер свечи, по которой считают: "1h" по умолчанию, "1d" для дневного RSI, "15m" для внутридневного. Параметр length — период, по умолчанию 14; другое значение ставь, только если пользователь назвал его сам.
* Вопрос «что такое RSI», «как его читать», «какой период лучше» — это теория, а не задача: инструмент для него не нужен.
