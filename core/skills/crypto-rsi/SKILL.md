---
name: crypto-rsi
description: Расчёт RSI (индекса относительной силы) по свечам Binance. Поддерживаются только BTC и ETH.
---
RSI считает только инструмент "get_crypto_rsi". По свечам из "get_crypto_historical_klines" он не выводится — это отдельный расчёт, а не поле в данных.

* Просят RSI по монете, кроме BTC и ETH, и больше ни по чему — плана нет: canExecute=false, а в fallbackMessage напиши, что RSI пока считается только для BTC и ETH, и перечисли доступное для остальных монет: цена, суточные объёмы, свечи, стакан.
* Просят сразу по нескольким монетам, и среди них есть BTC или ETH — canExecute=true и шаг "get_crypto_rsi" для КАЖДОЙ названной, включая неподдерживаемые: инструмент откажет по ним сам и назовёт причину, а она попадёт в отчёт. Это лучше, чем молча пропустить половину вопроса.
* interval и length указывай, только если пользователь назвал их сам.
* «Что такое RSI», «как его читать», «какой период лучше» — теория, а не задача: инструмент не нужен.
