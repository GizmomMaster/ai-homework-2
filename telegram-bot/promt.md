Разработать Telegram-бота.

Требования к функционалу:
- Бот должен принимать текстовое сообщение от пользователя в Telegram
    - Бот будет развенут на локальном компьютере
- Должен отправить полученный текст в качестве запроса в API нейросети
    - Сначала будет интеграция с api Ollama. В коде проекта надо заложить возможность буду-щего расширения этого функционала, чтобы можно было просто переключать интеграцию между разными программами, которые позволяют запускать большие языковые модели (LLM) на локальном компьютере
- Полученный ответ модели вернуть обратно пользователю в чат Telegram
- Запоминать историю общения с пользователем не нужно
    - Каждое новое сообщение обрабатывается как независимый одноразовый запрос
Технические требования:
- Для реализации проекта используем JavaScript(Node.js)
- Сделать работу с Telegram Bot API без сторонних библиотек (на чистых HTTP-запросах)
Безопасность и конфигурация:
- TELEGRAM_BOT_TOKEN будем хранить в .env-файле и передавать через переменные окружения (не зашивать ключи в код и не пушить в git)
